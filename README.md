# 🌟 About

**Matplotlib** is one of the most popular Python libraries used for creating **graphs, charts, and data visualizations**.

It allows Data Analysts, Data Scientists, and Machine Learning Engineers to transform raw data into meaningful visual insights.

# 📈 Sample Line Plot

```python
import matplotlib.pyplot as plt

x=[1,2,3,4,5]
y=[10,20,15,30,25]

plt.plot(x,y)

plt.title("Line Plot")

plt.xlabel("X Axis")

plt.ylabel("Y Axis")

plt.grid(True)

plt.show()
```

# 💻 Example Charts

## 📈 Line Plot

```python
plt.plot(x,y,color="blue",marker="o")
```

---

## 📊 Bar Chart

```python
plt.bar(x,y,color="green")
```

---

## 🥧 Pie Chart

```python
plt.pie(y,labels=x,autopct="%1.1f%%")
```

---

## 🎯 Scatter Plot

```python
plt.scatter(x,y,color="red")
```

---

## 📉 Histogram

```python
plt.hist(data,bins=10)
```

---

## 📦 Box Plot

```python
plt.boxplot(data)
```
